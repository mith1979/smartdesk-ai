# NovaTech Solutions — Company Device Updates

This is a fictional guide generated for the SmartDesk AI capstone.
All company rules, contacts, and processes are demonstration values.

## Scope
Company-managed laptops receive operating-system and security updates through IT-managed tools. Employees must keep these tools enabled. This guide does not authorize updates or administration of personal devices.

## Scheduling a Restart
When an IT-managed update asks for a restart, save your work and follow the deadline displayed in the update notice. Use the available scheduling option if it is offered. If a deadline conflicts with essential work, contact helpdesk@novatech.example before that deadline with the asset ID, displayed deadline, and business reason. An extension requires IT approval.

## Preparing for an Update
Connect the laptop to power and ensure that important work is saved in its approved company location. Close applications when the update tool requests it. Do not interrupt installation or power off a device while an update is actively applying unless IT instructs you to do so.

## Failed or Repeated Updates
Record the update name, error text, operating-system version, asset ID, and failure time. Contact IT if the tool reports failure or repeatedly asks for the same installation. Do not download unofficial update packages, disable endpoint protection, or change administrator settings.

## Support and Limits
IT determines recovery steps for a failed update. This guide does not define operating-system rollback procedures, outage recovery, or equipment replacement eligibility. SmartDesk can collect an issue description but cannot install an update or grant administrator access.

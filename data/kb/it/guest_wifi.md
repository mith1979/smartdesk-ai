# NovaTech Solutions — Guest Wi-Fi Access

This is a fictional guide generated for the SmartDesk AI capstone.
All company rules, contacts, and processes are demonstration values.

## Scope
The NovaTech-Guest wireless network provides internet access for visitors. Employees hosting visitors may request temporary guest access. It does not provide access to internal applications, shared drives, or the company VPN. Guest Wi-Fi access does not authorize a personal device for company work.

## Requesting Access
The employee host emails helpdesk@novatech.example with the visitor name, host employee email, office location, visit date, and business purpose. Request access at least 1 working day before the visit. IT supplies the approved connection instructions to the host. Do not include identity documents or payment information in a SmartDesk ticket.

## Connecting and Expiry
Select NovaTech-Guest and follow the temporary instructions supplied by IT. Access expires at the end of the approved visit date. For another day, the host must request an extension; access does not renew automatically. Do not share a visitor access code with other visitors.

## Connection Problems
Check that you selected the guest network and that the approved visit date is current. If access still fails, ask the host to contact IT with the office location, error text, and approximate failure time. Never include the access code in a ticket.

## Support and Limits
Contact helpdesk@novatech.example for assistance. This guide does not define guest network availability guarantees, internal network permissions, or personal-device VPN exceptions. IT must approve any access change.

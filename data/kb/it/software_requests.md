# NovaTech Solutions — Software Installation and License Requests

This is a fictional IT guide for the SmartDesk AI capstone.
All processes and timelines are demonstration rules.

## Scope
This guide applies to software used for company work
on company-managed Windows, macOS, and Ubuntu laptops.

## Software Already in the Software Center
1. Open the fictional NovaTech Software Center.
2. Search for the application.
3. If Install is available, select it.
4. If the application requires approval or a license,
   submit a request to IT.

An application appearing in the catalog does not guarantee
that a paid license has been assigned to you.

## Requesting New Software or a Paid License
Send a request to helpdesk@novatech.example with:
- Employee email.
- Application name and vendor.
- Business purpose.
- Operating system.
- Manager's name and written approval.
- Required date, if applicable.

Do not include passwords, payment-card details, or license keys.

## Approval Process
- The manager approves the business need.
- IT checks compatibility and security.
- Finance approves any purchase.
- IT arranges installation or assigns the license.

IT acknowledges a complete request within 2 working days.
This is an acknowledgment target, not an installation guarantee.
Completion depends on review, purchasing, and license availability.

## Installation Problems
If an approved installation fails:
1. Record the application name and exact error message.
2. Restart the laptop if the installer requests it.
3. Retry once.
4. Contact IT if the installation still fails.

Do not disable endpoint protection or use an unofficial installer.
If administrator credentials are requested, contact IT.

## Purchasing Restrictions
Do not purchase software independently and assume reimbursement.
Follow this approval process before any purchase.

## License Renewal or Removal
Contact IT before a license expires if it is still required.
Notify IT when you no longer need an application or license.

IT manages reassignment and removal.
Do not share your assigned account or license with another employee.

## Support and Limits
Contact: helpdesk@novatech.example.
This is a demonstration address.

This guide does not guarantee approval for a specific application
or define individual software prices.
Refer those questions to IT.
